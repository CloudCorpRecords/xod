# Roadmap

Xod 0.1 is the first public version. Here's what's next. Ideas and pull requests are welcome; see [CONTRIBUTING.md](../.github/CONTRIBUTING.md).

## Next
- **Faster answers on 16 GB Macs.** Fewer model calls per answer and a smaller default model, so a researched answer takes well under a minute.
- **Signed, notarized Mac app.** No security warning on first open.
- **One-click connected apps.** Ready-made setups for Gmail, Calendar, Notion and GitHub.
- **Spoken replies.** Xod answers out loud with an on-device voice.

## Later
- **Shareable routine templates**, like "weekly competitor check" or "morning brief".
- **Approve from your phone:** approve or decline pending actions when you're away from the Mac.
- **More Macs and Linux:** Intel Macs (cloud or Ollama models) and Linux.

## Shipped in 0.1
One-download install (everything inside the app) · built-in AI engine and first-run setup · routines · activity log with undo · connected apps (MCP) in both directions · shareable reports · smart model routing with a budget · add-on packs · local voice input · self-healing tool calls and a health check · on-device images and video · gated self-editing.
