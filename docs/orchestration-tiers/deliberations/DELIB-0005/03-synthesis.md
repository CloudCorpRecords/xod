## Proposition under synthesis

Under what conditions do deliberation, synthesis, and operational memory improve orchestration judgment rather than degrade it?

## Current conclusion

Three claims are registered as proposed, each carrying the instrument the skeptical review required:

- **CLM-022 (deliberation calibration).** Structured deliberation beats single pass judgment only with private first verdicts, an assigned skeptic, and preserved dissent. Calibration is scored as verdict accuracy against double scored ground truth, plus mean confidence error, in a factorial ablation of the three conditions. (OQ-15 instrumented.)
- **CLM-023 (synthesis provenance).** Every load bearing sentence in a synthesis, defined by the deletion test (removing it changes a verdict, confidence, or next step), must attribute to a note or artifact. The unattributable fraction is the measurement. (OQ-16 instrumented, using the link discipline DELIBERATION-PROTOCOL section 11 already demands.)
- **CLM-024 (memory provenance and selection).** Each retained operational item carries origin class (observed, instructed, inferred, deliberated), scope, and expiry or review condition; items without an explicit condition expire at their scope interval's end, surviving only by recorded re-derivation or re-instruction; inferred items are never silently promoted to observed. Selection retains commitments, caused effects, authority, and open questions; the rest expires. (OQ-17 and OQ-18 instrumented jointly, because selection without provenance returns guesses as facts and provenance without selection drowns work in trivia.)

## Decisive arguments

The review's through line is correct: each claim needed its losing observation written down. With the metric, the default, and the deletion test added, each claim can now be refuted by a specified result, which is the registry's admission price. The memory default is the synthesis's most consequential adoption: expiry by default converts Tier 6 memory from archive to maintained position, and it gives PROTOCOLS Tier 6 assessments a scorable behavior (sample expired items; check for silent survival) where previously there was only a design preference.

## Agreed facts

- No experimental evidence yet supports any of the three claims. All register as proposed.
- CLM-006 constrains all deliberation claims: participant count never substitutes for independent evidential paths.
- The origin class set is deliberately coarse (four classes) so it survives summarization; domain refinements are amendments, not refutations, unless shown to mislead.

## Dissent preserved

The proposal's worry that CLM-022 may split by participant class (AI panels versus human panels) is preserved as the claim's first expected narrowing. If factorial evidence shows the conditions helping one class and not the other, the claim narrows by correction under the verdict change rules rather than failing wholesale, and this note is its starting point.
